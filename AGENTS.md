Run `npm run build:loom` for preflight, build, and final signing, or `npm run sign:loom -- --app <staged-app>` for an existing staged bundle. `npm run sign:loom -- --check` validates the identity before expensive builds. Never create, import, rotate, or retrieve signing keys/certificates automatically; never fall back to ad-hoc signing.

The signing script passes the already-validated fingerprint to pinned `@electron/osx-sign` with its basic-policy lookup disabled, keeps hardened runtime and `macos.entitlements`, disables timestamps/provisioning/automatic team entitlements, and requires strict deep verification plus a certificate-bound designated requirement without `cdhash`.

If keychain signing access is denied, stop and surface the error; do not retry prompts, reset global privacy permissions, or weaken signing/trust requirements.
